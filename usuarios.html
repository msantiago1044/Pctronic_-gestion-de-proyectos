¿Cómo creo un usuario nuevo para un empleado?

Entra a tu proyecto de Supabase → Authentication → Users → Add user, crea el correo y una contraseña temporal, y compártesela a la persona. En cuanto inicie sesión aquí por primera vez, aparecerá automáticamente en esta lista para que le asignes su rol.

Restablecimiento de contraseñas

Los usuarios deben solicitar cualquier cambio o recuperación de contraseña directamente al Super Usuario. Para restablecer una clave, ingresa a Supabase → Authentication → Users, busca al usuario y usa Send password recovery o actualiza su contraseña temporal.
